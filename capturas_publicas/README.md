# Capturas públicas

A diferencia de `capturas/` (privada, excluida del repo vía `.gitignore`), lo que esté
en esta carpeta **sí se sube a GitHub**.

Antes de mover un `.pcap` aquí, revisar que no contenga datos de terceros captados
incidentalmente durante la prueba (SSID/BSSID de redes vecinas reales, MAC no
aleatorizadas de clientes ajenos, etc.). Si la captura solo contiene el AP/cliente de
laboratorio propio, es candidata a publicarse.
